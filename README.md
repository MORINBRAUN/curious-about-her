# Curious About Her

An app for two. He gets curious. She feels it.

A small web app that lives on each partner's phone. Messages between the two phones travel as WhatsApp links;
the message sits after the `#` in the link, so it never reaches the website host. No accounts, no server, no data in this repository.

- `index.html`: the whole app (English and Hebrew)
- `manifest.json`, `icon.svg`: lets you add it to your home screen
- `sw.js`: keeps it working offline

Working copy and project notes live in the private workspace (`M_Personal_Projects/projects/couples-app/`).
